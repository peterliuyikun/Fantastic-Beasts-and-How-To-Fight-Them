# 🐉 Fantastic Beasts and How to Fight Them

A web-based monster battle game inspired by Blooket's Monster Brawl mode and the Fantastic Beasts universe.

## 🎮 Features

### User Authentication
- Create account with username and display name
- Secure login/logout system
- Password management
- User data persistence via localStorage

### Avatar Creator
- **Body Shapes**: Round, Square, Triangle, Star, Diamond
- **Colors**: 8 vibrant body colors + 6 background colors
- **Eyes**: Normal, Big, Angry, Wink, Cyclops
- **Mouth**: Smile, Frown, Open, Tongue, Sharp teeth
- **Accessories**: Glasses, Hat, Bow, Crown, or None
- **Randomize**: One-click random avatar generation
- **Canvas-based rendering** for crisp, scalable graphics

### Main Menu
- Beautiful dark theme UI
- User profile display with avatar
- Navigation to all game sections
- Level and XP tracking

### Settings
- **Appearance**: Dark/Light/Fantasy themes
- **Audio**: Sound effects, music, volume control
- **Game**: Difficulty levels, hints toggle
- **Account**: Change display name and password
- **Data**: Clear all saved data

### Game Modes (Coming Soon)
- **Monster Brawl**: Battle against other beasts
- **Campaign**: Adventure through the wizarding world
- **Arena**: Survive waves of enemies

## 🛠️ Tech Stack

- **HTML5** - Structure
- **CSS3** - Styling with CSS variables and animations
- **Vanilla JavaScript** - No frameworks, pure JS
- **Canvas API** - Avatar rendering
- **localStorage** - Data persistence

## 🎨 Design

- Responsive design for mobile and desktop

- Modern glassmorphism UI elements
